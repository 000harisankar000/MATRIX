# Zenith 🚀

Zenith is a distraction-blocking Chrome extension designed to introduce intentional friction to your browsing habits. Instead of just hard-blocking sites, Zenith gives you creative ways to earn your screen time.

## ✨ Features

- **🐍 Snake Game Mode:** Want to visit a restricted site? You have to earn it. Play a quick game of Snake and score at least 10 points before the site unlocks.
- **📝 Text Mode:** A strict roadblock for your worst distractions. 
  - **Global Text:** Blocks preset distractor sites.
  - **Custom Text:** Tailor your own list of restricted sites.
  - *Note:* The only way around this mode is disabling the extension itself, keeping you accountable!
